# NightGuard 改进计划 v1.0

## 一、计划概述

### 1.1 目标
基于前期深度分析，对 NightGuard 进行系统性优化，使其 UI/UX 符合 2024-2025 年美国 iOS 健康类 App 主流趋势，同时增强核心功能竞争力。

### 1.2 优化范围
- **视觉层**：UI 风格现代化（减少渐变、增加毛玻璃卡片、数据可视化）
- **功能层**：Apple Health 集成、Widget/Live Activity、Wind Down 提醒
- **架构层**：代码复用、模块单一职责、废弃代码清理
- **体验层**：Onboarding 优化、Stats 数据洞察、Paywall 转化率

### 1.3 核心原则
1. **需求可验证**：每个优化点包含需求描述、生成规则、检验标准（代码示例 + 测试用例）
2. **单一职责**：一个功能一个模块，高内聚低耦合，命名语义化
3. **最小代码**：优先复用现有模块，符合"三次法则"（遇到三次再抽象）
4. **重构清理**：替换代码时标记废弃 → 验证无影响 → 删除，提交信息注明清理范围
5. **风格一致**：新代码与现有软件格调、功能、UI 保持一致
6. **优先继承**：Setting 等存在继承关系的模块优先继承而非硬编码

### 模块 A：UI 基础组件层（NGDesignSystem）

#### A1. 需求描述
建立统一的视觉组件库，将重复出现的卡片、按钮、渐变模式抽象为可复用组件，确保全 App 视觉一致性。

#### A2. 生成规则
- **文件位置**：`Views/Components/`
- **命名规范**：`NG` 前缀（NightGuard）+ 组件语义名
- **继承关系**：所有组件继承 `View`，不使用自定义协议（保持 SwiftUI 原生）

```swift
// Models/SleepRecord+Analytics.swift
import Foundation

extension SleepRecord {
    /// 睡眠质量评分 (0-100)
    var sleepQualityScore: Int {
        let durationHours = durationSeconds / 3600
        let idealDuration = 8.0
        let durationScore = min(100, Int((durationHours / idealDuration) * 100))

        let bypassPenalty = min(30, bypassAttemptCount * 10)
        return max(0, durationScore - bypassPenalty)
    }

    /// 是否达标（7小时以上且无绕过）
    var isGoalMet: Bool {
        durationSeconds >= 7 * 3600 && bypassAttemptCount == 0
    }
}
```

### 模块 C：Apple Health 集成（HealthKitModule）

#### C1. 需求描述
集成 Apple HealthKit，读取用户 Apple Watch 睡眠数据，写入 NightGuard 屏蔽事件，增强数据可信度。

#### C2. 生成规则
- **文件位置**：`Services/HealthKitManager.swift`
- **权限配置**：在 `NightGuard.entitlements` 中添加 `com.apple.developer.healthkit`
- **Info.plist**：添加 `NSHealthShareUsageDescription` 和 `NSHealthUpdateUsageDescription`
- **数据模型复用**：将 HealthKit 数据转换为 `SleepRecord` 存储到 SwiftData

#### C3. 代码示例

**C3.1 HealthKitManager**
```swift
// Services/HealthKitManager.swift
import HealthKit
import SwiftData

@MainActor
final class HealthKitManager: ObservableObject {
    static let shared = HealthKitManager()

    private let healthStore = HKHealthStore()

    /// 检查并请求 HealthKit 权限
    func requestAuthorization() async throws -> Bool {
        guard HKHealthStore.isHealthDataAvailable() else { return false }

        let sleepType = HKObjectType.categoryType(forIdentifier: .sleepAnalysis)!
        let typesToRead: Set = [sleepType]
        let typesToWrite: Set<HKSampleType> = [] // 只读模式

        try await healthStore.requestAuthorization(toShare: typesToWrite, read: typesToRead)
        return true
    }

    /// 读取最近 N 天的睡眠数据并转换为 SleepRecord
    func fetchSleepRecords(days: Int = 7) async -> [SleepRecord] {
        guard HKHealthStore.isHealthDataAvailable() else { return [] }

        let sleepType = HKObjectType.categoryType(forIdentifier: .sleepAnalysis)!
        let calendar = Calendar.current
        let endDate = Date()
        let startDate = calendar.date(byAdding: .day, value: -days, to: endDate)!

        let predicate = HKQuery.predicateForSamples(withStart: startDate, end: endDate, options: .strictStartDate)
        let sortDescriptor = NSSortDescriptor(key: HKSampleSortIdentifierEndDate, ascending: false)

        return await withCheckedContinuation { continuation in
            let query = HKSampleQuery(
                sampleType: sleepType,
                predicate: predicate,
                limit: HKObjectQueryNoLimit,
                sortDescriptors: [sortDescriptor]
            ) { _, samples, error in
                guard let samples = samples as? [HKCategorySample] else {
                    continuation.resume(returning: [])
                    return
                }

                let records = self.aggregateSleepRecords(from: samples)
                continuation.resume(returning: records)
            }
            self.healthStore.execute(query)
        }
    }

    private func aggregateSleepRecords(from samples: [HKCategorySample]) -> [SleepRecord] {
        // 按日期聚合睡眠样本，生成 SleepRecord 数组
        var recordsByDate: [Date: (bedtime: Date, wakeTime: Date, duration: TimeInterval)] = [:]
        let calendar = Calendar.current

        for sample in samples where sample.value == HKCategoryValueSleepAnalysis.asleep.rawValue {
            let date = calendar.startOfDay(for: sample.startDate)
            if var existing = recordsByDate[date] {
                existing.bedtime = min(existing.bedtime, sample.startDate)
                existing.wakeTime = max(existing.wakeTime, sample.endDate)
                existing.duration += sample.endDate.timeIntervalSince(sample.startDate)
                recordsByDate[date] = existing
            } else {
                recordsByDate[date] = (sample.startDate, sample.endDate, sample.endDate.timeIntervalSince(sample.startDate))
            }
        }

        return recordsByDate.map { date, data in
            SleepRecord(
                date: date,
                bedtime: data.bedtime,
                wakeTime: data.wakeTime,
                durationSeconds: data.duration,
                bypassAttemptCount: 0,
                wasHardLock: false
            )
        }.sorted { $0.date > $1.date }
    }
}

// 测试用例（需在真机或 HealthKit 模拟环境下测试）：
// 1. 首次打开请求权限弹窗
// 2. 授权后拉取最近 7 天数据
// 3. 无 Apple Watch 数据时返回空数组不崩溃
// 4. 数据聚合正确（跨午夜的睡眠算前一天）
```

**D3.1 Widget 时间线 Provider**

```swift
// Widget/SleepStatusWidget.swift
import WidgetKit
import SwiftUI

struct SleepStatusEntry: TimelineEntry {
    let date: Date
    let isShieldActive: Bool
    let streak: Int
    let remainingTime: String
}

struct SleepStatusProvider: TimelineProvider {
    private let defaults = UserDefaults(suiteName: AppGroupConstants.suiteName)

    func placeholder(in context: Context) -> SleepStatusEntry {
        SleepStatusEntry(date: Date(), isShieldActive: true, streak: 5, remainingTime: "6h 30m")
    }

    func getSnapshot(in context: Context, completion: @escaping (SleepStatusEntry) -> Void) {
        completion(currentEntry())
    }

    func getTimeline(in context: Context, completion: @escaping (Timeline<SleepStatusEntry>) -> Void) {
        let entry = currentEntry()
        let nextUpdate = Calendar.current.date(byAdding: .minute, value: 1, to: Date())!
        let timeline = Timeline(entries: [entry], policy: .after(nextUpdate))
        completion(timeline)
    }

    private func currentEntry() -> SleepStatusEntry {
        SleepStatusEntry(
            date: Date(),
            isShieldActive: defaults?.bool(forKey: AppGroupKeys.isShieldActive) ?? false,
            streak: defaults?.integer(forKey: "widget_streak") ?? 0,
            remainingTime: SimulatedShutdown.shared.remainingTime
        )
    }
}
```

#### F1. 需求描述

#### F2. 生成规则

#### F3. 代码示例

**F3.1 WindDownManager**
```swift
// Services/WindDownManager.swift
import Foundation
import UserNotifications

final class WindDownManager {
    static let shared = WindDownManager()

    private let notificationManager = NotificationManager.shared
    private let scheduleManager = ScheduleManager.shared

    /// 就寝前提醒间隔（分钟）
    let windDownIntervals: [Int] = [60, 30, 15]

    func scheduleWindDownReminders() {
        guard scheduleManager.isEnabled else {
            cancelWindDownReminders()
            return
        }

        cancelWindDownReminders()

        for interval in windDownIntervals {
            let reminderTime = calculateWindDownTime(minutesBefore: interval)
            scheduleWindDownNotification(at: reminderTime, minutesBefore: interval)
        }
    }

    func cancelWindDownReminders() {
        let identifiers = windDownIntervals.map { "winddown_\($0)min" }
        UNUserNotificationCenter.current().removePendingNotificationRequests(withIdentifiers: identifiers)
    }

    private func calculateWindDownTime(minutesBefore: Int) -> DateComponents {
        let calendar = Calendar.current
        var bedComponents = DateComponents()
        bedComponents.hour = scheduleManager.bedtimeHour
        bedComponents.minute = scheduleManager.bedtimeMinute

        guard let bedTime = calendar.date(from: bedComponents) else {
            return bedComponents
        }

        let reminderTime = calendar.date(byAdding: .minute, value: -minutesBefore, to: bedTime)!
        return calendar.dateComponents([.hour, .minute], from: reminderTime)
    }

    private func scheduleWindDownNotification(at time: DateComponents, minutesBefore: Int) {
        let content = UNMutableNotificationContent()
        content.title = "Wind Down in \(minutesBefore)m"
        content.body = windDownMessage(minutesBefore: minutesBefore)
        content.sound = .default
        content.categoryIdentifier = "WIND_DOWN"

        let trigger = UNCalendarNotificationTrigger(dateMatching: time, repeats: true)
        let request = UNNotificationRequest(
            identifier: "winddown_\(minutesBefore)min",
            content: content,
            trigger: trigger
        )

        UNUserNotificationCenter.current().add(request)
    }

    private func windDownMessage(minutesBefore: Int) -> String {
        switch minutesBefore {
        case 60: return "Start winding down. Put your phone away soon."
        case 30: return "30 minutes until bedtime. Time to relax and unplug."
        case 15: return "Bedtime in 15 minutes. NightGuard will activate soon."
        default: return "Bedtime approaching. Get ready to sleep."
        }
    }
}

// 测试用例：
// 1. 设置就寝时间 22:00，应生成 21:00、21:30、21:45 三个提醒
// 2. 禁用计划时取消所有 Wind Down 通知
// 3. 通知内容根据时间间隔变化
```

## 六、附录：命名规范

### 6.1 文件命名
- 视图：`{Name}View.swift`
- ViewModel：`{Name}ViewModel.swift`
- 模型：`{Name}.swift` 或 `{Name}+Extension.swift`
- 服务：`{Name}Manager.swift` / `{Name}Service.swift`
- 组件：`NG{Component}.swift`

### 6.2 类/结构体命名
- 视图结构体：`{Name}View`
- ViewModel：`{Name}ViewModel`
- 模型：`{Name}`（名词）
- 管理器：`{Name}Manager`（单例）
- 协议：`{Name}Protocol` 或 `{Name}able`

### 6.3 方法命名
- 动作方法：`verbNoun()`（如 `startShield()`）
- 查询方法：`isNoun` / `hasNoun` / `formattedNoun`
- 私有方法：`private func verbNoun()`
